## What it is

**Native Windows GUI (NWG)** is a Rust library for building **truly native**
GUI desktop applications for Microsoft Windows (it wraps the Win32 API). The
docs describe it as "the BEST (and only) rust library to develop truly native
GUI applications on desktop for Microsoft Windows."

- Current docs target **NWG 1.0** — the 3rd and final major version.
- API reference is hosted on docs.rs:
  https://docs.rs/native-windows-gui/1.0.0/native_windows_gui/
