# Are We GUI Yet?

> Source: https://areweguiyet.com/
> Retrieved: 2026-06-25
> Type: Community catalog (summary + extracted crate list)

## What it is

A community-maintained catalog tracking the state of GUI and UI development in
Rust. Tagline: *"The roots aren't deep but the seeds are planted."* It lists
GUI-related crates with tags and links (crates.io / GitHub / docs), plus a feed
of recent ecosystem news and blog posts.
